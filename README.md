# PROJECT ARCHIMEDES

A minimal, reproducible "hypothesis → analysis → critique" loop on synthetic microbial growth curves.
Full write-up in Korean: [ARCHIMEDES_Report.md](ARCHIMEDES_Report.md).

Five rule-based roles pass structured records to each other: Knowledge, HypothesisGenerator, Analyst,
Critic and Orchestrator. No language model is called, and the data are generated by the script, so the
results show only that the pipeline recovers planted effects and rejects a negative control.

## Run

```bash
pip install -r requirements.txt
python prototype/archimedes_prototype.py     # writes prototype/run_result.json
python prototype/test_prototype.py           # 15 tests
```

Options: `--seed`, `--reps`, `--hours`, `--timepoints`, `--out`.

## Files

- `prototype/archimedes_prototype.py` — data generator, the five roles, CLI
- `prototype/test_prototype.py` — unit tests, including a check that `run_result.json` matches a fresh run
- `prototype/run_result.json` — output of the default run (seed 42)
